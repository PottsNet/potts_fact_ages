# Changelog

All notable changes to Potts Fact Ages will be documented in this file.

## 1.0.2

### Fixed

- Uses the server-calculated age row for Birth, so an exact birth date now displays an age of 0 days instead of a browser-derived approximate age.
- Removes the browser-side age-calculation fallback that could attach ages to non-event metadata such as `_FSFTID` and record-change dates.
- Adds German translations for the approximate-age phrases and category labels reported in GitHub issue #2.
- Normalises the internal `CLOSE_RELATIVE` label before it is displayed.
- Uses webtrees' translated **Age** label on fact/event tiles.

### Performance

- Caches calculated age rows for the current individual within each PHP request.
- Reduces the MutationObserver to child-list changes only instead of observing class, style and ARIA attribute changes across the whole page.
- Removes click-triggered rescans and reduces eight delayed scans to one short delayed pass.
- Keeps title labels based on server-calculated rows rather than running a second English-only browser age calculator.

### Compatibility

- Retains the Potts Biography exclusion introduced in 1.0.1.
- Retains the direct webtrees Tabs settings link introduced in the beta series.

## 1.0.1

### Fixed

- Excludes Potts Biography content from browser-side fact-tile scanning.
- Prevents a second Potts Fact Ages label being inserted beside ages already rendered by Biography.
- Retains normal age labels on the webtrees Facts and events tab.

## 1.0.0

### Changed

- Promoted the tested `1.0.0-beta.7` build to a regular stable release.
- Updated internal version from `1.0.0-beta.7` to `1.0.0`.
- Updated README and release notes from beta wording to stable release wording.

### Added

- Added `latest-version.txt`.
- Added update service support for webtrees and Custom Module Manager.
- Added `customModuleLatestVersionUrl()` so the module should not show `Update service: None`.

## 1.0.0-beta.7

### Fixed

- Fixed title-tile age labels when a fact note contains a more specific date than the actual event date.
- Improved the browser-side date matcher so notes, sources and media captions are ignored when detecting the event date for an existing fact tile.
- Prevents cases such as a birth note mentioning a later marriage date from making later events calculate from the wrong starting date.

## 1.0.0-beta.6

### Added

- Added a **Tabs settings** link to the Potts Fact Ages settings page.
- Added a helper panel explaining that the separate Potts Fact Ages tab must also be enabled and ordered in webtrees **Control panel > Modules > Tabs**.
- Added the Tabs settings link to both the top and bottom settings-page navigation bars.

## 1.0.0-beta.5

### Fixed

- Fixed the title-tile-only display option so the separate **Potts Fact Ages** tab is hidden even when title labels are enabled.
- Kept the title-label enhancer and tab-hiding script independent so display-location settings behave as separate controls.

### Notes

- Ages shown by webtrees or another historical-facts module inside its own historical events tab are not generated by Potts Fact Ages. Potts Fact Ages only controls its own tab and its own title-tile labels.

## 1.0.0-beta.4

### Fixed

- Fixed the display-location setting so the title-tile-only option hides the **Potts Fact Ages** tab from the page navigation.
- Improved standalone tab content so ordinary personal facts are added directly from the individual record before expanded webtrees facts are merged in.
- Added de-duplication when combining direct personal/family facts with webtrees service-provided facts.

## 1.0.0-beta.3

### Fixed

- Fixed the settings-page **Home page** link so it uses an absolute webtrees site URL instead of being interpreted as a `potts_fact_ages` module action.
- Made the settings-page navigation URLs safer for pretty URLs and subdirectory webtrees installs.

## 1.0.0-beta.2

### Added

- Added navigation buttons to the module settings page.
- Added links back to the module list, control panel and home page.
- Added a browser Back button for returning to the previous page.

### Changed

- Updated the settings page so administrators are not left on a dead-end configuration page after saving preferences.

## 1.0.0-beta.1

First public GitHub beta release.

### Added

- Renamed the public module from **Fact Ages** to **Potts Fact Ages**.
- Renamed the install folder from `fact_ages` to `potts_fact_ages` for the public release.
- Added standalone webtrees tab support.
- Added optional age labels on the existing Facts and events title tiles.
- Added a setting to show ages in the tab, on event title tiles, or both.
- Added settings for personal facts, family facts, close relative events, associate events, historical facts and category labels.
- Added configurable GEDCOM tag inclusion.
- Added timeline-card and compact-table display styles.
- Added simple, detailed and combined age-display options.
- Added a styled module settings page.
- Added browser-side diagnostics via `window.pottsFactAgesStatus`.
- Added support for AJAX-loaded facts content.
- Added safe placement logic for two-column fact/event layouts.

### Changed

- Removed the original dependency on Vesta.
- Reworked the module as a standalone webtrees 2.2 custom module.
- Improved age-label placement inside the left fact/event tile.
- Centred age labels so they align visually with centred fact/event titles.
- Improved protection against duplicate labels and misplaced labels in side panels.

### Known limitations

- Event-title labels depend on rendered webtrees markup and may need testing with unusual custom themes.
- Ages are calculated from the first recorded birth date only.
- BCE dates and phrase-only dates are not currently supported.
