# Contributing

Thanks for your interest in Potts Fact Ages.

Helpful bug reports include:

- webtrees version
- PHP version
- theme name
- browser and operating system
- whether the issue affects the separate tab, the event-title labels, or both
- a screenshot if the issue is visual
- the output of `window.pottsFactAgesStatus` from the browser console if event-title labels are not working

Please avoid posting private family data in public issues. Use a test individual or blur sensitive information in screenshots.
